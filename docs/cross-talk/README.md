# 会话沟通区

各子项目开发会话在此共享工作状态。**每个会话只维护自己创建的文件**，可读取其他文件借鉴。

## 约定

- 文件按子项目命名：`<sub-project>.md`（如 `dsh-pet.md`、`dsh-cbw-memory.md`、`root.md`）
- **覆盖式更新**：文件反映当前状态，不堆历史日志（避免无限增长）
- **只改自己的文件**，不碰别人的——零冲突
- 可读取其他会话的文件了解进展、借鉴经验、响应请求
- 完成任务后可清空自己的文件内容（写"无进行中任务"），但保留文件

## 文件结构

每个文件含以下段落：

- **正在进行**：当前任务、进度
- **遇到的困难**：阻塞问题、待解决
- **发现的经验**：可复用的模式、踩坑教训、性能发现
- **对其他会话的通知/请求**：接口变更预告、依赖请求、协调事项
